# Tableau Tendance Frontend

Angular storefront for **Tableau Tendance**, a Tunisian e-commerce website for decorative wall art and canvas paintings.

## Purpose

This project is a product-sales website, not a service or appointment platform. The customer-facing experience focuses on:

- Decorative tableaux and wall art
- Product catalog and category filtering
- Cart and order flow
- Cash on delivery in Tunisia
- Contact and WhatsApp ordering support

Service booking, boutique reservations, beauty services, and appointment CTAs are not part of the public website direction.

## Development

Install dependencies once:

```bash
npm install
```

Start the local development server:

```bash
npm start
```

Open `http://localhost:4200/`.

## Build

Compile the Angular app:

```bash
npm run build
```

The production output is generated in `dist/`.
